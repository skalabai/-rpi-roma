# УчёбаПро — ЛР2

Учебная платформа на React (Vite) без сторонних UI-библиотек.

## Запуск

```bash
cd edu-platform
npm install
npm run dev
```

Откройте адрес из терминала (обычно `http://localhost:5173`).

## Что сделано

- Каталог 10 лекторов с фото, дисциплинами, темами и тарифами
- Страницы: главная, лекторы, профиль лектора, курсы, о платформе, контакты
- Фильтр лекторов и поиск по курсам
- Навигация через состояние React (без React Router)
